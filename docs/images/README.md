# Documentation screenshots

These PNGs capture the running application in a separate local demo workspace at
1600 × 1000. They are browser screenshots, not interface mockups.

- `editor.png`: three imported sources, a title layer, and the shared visual editor.
- `asset-preview.png`: the asset gallery and its anchored floating video preview.

The illustrated landscape media was created for these screenshots using original
SVG shapes and encoded into local demo videos. No personal footage, credentials,
third-party stock images, or user projects are included. The title was added through
the same project editing API used by the application and agents.
